# Roman Sheikh Razan Portfolio

Personal portfolio website built from Roman Sheikh Razan's resume and verified
public GitHub profile.

## Run locally

Open `index.html` directly, or serve the folder with any static web server:

```powershell
python -m http.server 4173
```

Then visit `http://127.0.0.1:4173`.

## Main files

- `index.html` - portfolio content and project data
- `assets/css/styles.css` - responsive design and theme styles
- `assets/js/controllers/` - interactions and animations
- `assets/img/roman-profile.png` - profile photo
- `assets/Roman-Sheikh-Razan-Resume.pdf` - downloadable resume
